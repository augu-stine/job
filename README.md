# Placement Management System  

A web-based **Placement Management System** designed to streamline student profile management, job postings, and recruiter interactions. This system provides an efficient platform for **students to find job opportunities** and for **recruiters to connect with potential candidates**.  

## **Features**  
✅ Student profile creation and management  
✅ Recruiter job postings and access to student profiles  
✅ Job application and tracking system  
✅ Admin dashboard for system monitoring  
✅ Secure login and authentication system  

## **Technologies Used**  
- **Backend:** PHP, MySQL  
- **Frontend:** HTML, CSS, Tailwind CSS, Bootstrap  
- **Other Tools:** Git, GitHub
